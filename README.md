# Foobar2000 - Pandora Box Edition

Configurazione portatile completa di **Foobar2000 (v1.6)** con la skin **Pandora Box** ([VSThemes.org](https://vsthemes.org/en/skins/foobar2000/26149-pandora-box.html)).

## Caratteristiche
- **Columns UI** preconfigurato con la skin Pandora Box originale di Atarod.
- **VU Meter** analogico (Marantz 50201).
- **Waveform seekbar** interattiva.
- **Pannello LCD** centrale con informazioni dettagliate della traccia.
- **JSPlaylist** con supporto copertine album e scorrimento fluido.
- Controlli grafici personalizzati e potenziometro volume.
- Struttura **100% portatile** (tutte le configurazioni salvate in locale).

## Utilizzo
1. Clonare o posizionare la cartella in qualsiasi posizione desiderata (es. `D:\programmi\foobar2000`).
2. Installare i font presenti nella cartella `FONTS\` se non già presenti nel sistema.
3. Eseguire `foobar2000.exe`.
